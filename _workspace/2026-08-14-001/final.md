# 패티(Patti) 서비스 기획서

**Play And Talk Together with aI**

작성일: 2026-08-12 · 상태: 제출용 기획서

---

## 1. 서비스 개요

패티는 권리가 확보된 아동 영상을 AI가 사전에 분석하고 시청 도중 퀴즈·퍼즐·그림·움직임 활동을 제공하며 설정한 시간에 미디어 사용을 자연스럽게 마무리하도록 돕는 아동용 인터랙티브 미디어 서비스다. 아이가 직접 그린 그림은 AI 캐릭터로 완성되고 이 캐릭터가 영상 시청과 활동을 함께한다.

패티가 지향하는 바는 스크린 타임을 없애는 것이 아니다. 부모의 지속적인 개입 없이도 수동적인 시청을 참여 활동으로 바꾸고 종료 과정을 돕는 것이다.

- **초기 타깃**: 만 4~6세 아동과 부모
- **우선 지원 기기**: 안드로이드 태블릿

---

## 2. 문제 정의

### 부모와 아이

- 아이가 별다른 생각이나 표현 없이 영상을 연속으로 시청한다.
- 부모가 매번 옆에서 질문과 놀이를 준비하기 어렵다.
- 약속한 시간이 되어 영상을 끄면 종료 갈등이 생긴다.
- 교육 콘텐츠가 있어도 아이가 실제로 좋아하는 영상과 맞지 않을 수 있다.

### 서비스 운영

- 공개 영상이라도 상업적 재사용이 가능한 것은 아니다.
- 영상마다 활동과 노출 시점을 수작업으로 제작하기 어렵다.
- 생성형 AI의 오류와 아동 안전 문제를 통제해야 한다.

---

## 3. 솔루션

### 3.1 권리가 확인된 영상만 제공

패티는 임의의 YouTube 영상이 아니라 사용 권한이 확인된 영상만 제공한다.

- **무료**: CC·공공·직접 허가 콘텐츠 10~20편
- **유료**: 크리에이터·MCN·제작사와 계약한 콘텐츠 패키지

무료 콘텐츠로 기능과 유용성을 검증한 뒤, 특정 크리에이터 패키지, 특정 IP·시리즈 패키지, 동물·공룡·우주 등 주제 패키지, 연령·관심사별 패키지로 확장한다.

### 3.2 영상을 참여형 활동으로 전환

AI가 자막·장면·핵심 단어·재생 시간을 분석해 적절한 활동과 노출 시점을 미리 생성한다.

| 활동 | 예시 |
| --- | --- |
| 관찰·선택 퀴즈 | "방금 나온 자동차는 무슨 색이었을까?" |
| 기억·순서 활동 | 등장한 대상이나 행동 순서 맞추기 |
| 퍼즐 | 영상 주제와 관련된 그림 퍼즐 |
| 색칠·그리기 | 영상에서 본 대상 따라 그리기 |
| 마무리 | 주제에 대해 그리고 AI 캐릭터로 변환 |

아이가 원하지 않으면 활동을 건너뛸 수 있다. 건너뛰기가 반복되면 AI가 개입 간격을 늘린다.

### 3.3 미디어 사용 마무리

- 10~30초 이내의 마지막 활동 제공
- 활동 결과와 보상 저장
- 세션 완료 화면으로 전환
- 부모에게 시청 시간과 참여 결과 제공

목표는 반드시 오프라인 활동으로 넘어가는 것이 아니라, 패드 안에서도 활동을 완성해 충분한 종료감을 주는 것이다.

## 4. 서비스 흐름 & 사용자 경험

### 4.1 전체 서비스 흐름

```
권리가 확보된 영상 등록
→ AI 사전 분석
→ 활동·개입 시점 생성
→ 자동 검사와 운영자 검수
→ 상호작용 DB 저장
→ 앱에서 영상 재생
→ 적절한 시점에 활동 제공
→ 아이 반응에 따라 난이도·간격 조정
→ 마지막 활동
→ 세션 종료 및 부모 결과 제공
```

### 4.2 부모·아이 경험

```
부모가 시청 시간과 콘텐츠 설정
→ 영상 중간에 짧은 활동
→ 아이가 참여하거나 건너뛰기
→ 영상 재생
→ 마지막 활동
→ 세션 완료
→ 부모가 결과 확인
```

세션이 끝나면 부모는 다음을 확인한다.

- 실제 시청 시간
- 시청한 영상
- 활동 참여·건너뛰기 횟수
- 수행한 퀴즈·퍼즐·그림
- 관심을 보인 주제
- 부모 개입 없이 종료했는지 여부

초기에는 언어·인지 발달을 진단하거나 또래와 비교하지 않는다.

## 5. AI 자동화 설계

### 5.1 영상 등록 시

1. 자막·장면·핵심 단어 분석
2. 영상 유형과 권장 연령 분류
3. 활동과 개입 시점 후보 생성
4. 사실 오류·중복·유해성 자동 검사
5. 운영자 최종 검수
6. 승인된 결과만 DB에 저장

### 5.2 영상 시청 중

1. 현재 재생 위치 확인
2. 검수된 활동 중 하나 선택
3. 안전한 시점에 영상 일시 정지
4. 캐릭터와 활동 화면 제공
5. 아이 반응에 맞춰 힌트·난이도 조절
6. 활동 완료 또는 건너뛰기 후 영상 재생

AI는 활동을 실시간으로 무제한 생성하지 않는다. 사전에 생성·검수한 활동을 중심으로 질문 표현과 난이도만 제한적으로 조정한다.

---

## 6. 핵심 차별점

- 아이가 이미 관심을 두고 보는 영상에서 출발한다.
- 권리가 확보된 영상만 제공한다.
- 영상 맥락에 맞는 활동을 사전에 생성·검수한다.
- 아이의 반응에 따라 난이도와 개입 간격이 달라진다.
- 부모가 계속 옆에서 질문을 준비하지 않아도 된다.
- 체류시간 증가보다 설정한 시간에 끝내는 것을 목표로 한다.
- 무료 콘텐츠로 검증한 뒤 인기 콘텐츠 제휴 패키지로 확장한다.

---

## 7. 비즈니스 모델

### 7.1 무료 서비스

- CC·공공·직접 허가 콘텐츠 제공
- 패티의 상호작용과 종료 지원 기능 체험
- 서비스 기능 및 사용자 수요 검증

### 7.2 유료 서비스

- 크리에이터·MCN·제작사와 계약한 콘텐츠 패키지 판매
- 플랫폼과 권리자가 수익을 배분하는 B2B2C 구조

패티 유료 서비스의 핵심은 인기 키즈 IP 제작사 및 MCN 크리에이터와의 B2B 제휴로 프리미엄 콘텐츠 라이브러리를 넓히는 데 있다. 제휴사가 원본 영상 권한을 제공하면, 패티의 AI 엔진이 영상을 새로 제작하지 않고도 대화형 추론과 창작 미션을 결합한 '인터랙티브 팩'으로 재가공한다. 제휴사는 기존 영상 자산의 부가가치와 수익 배분(Revenue Share)을 얻고 아이들은 좋아하는 캐릭터와 직접 상호작용하는 몰입 경험을 얻는다.

## 8. MVP 범위

### 발표 데모

- Blender Studio `Spring` 영상 1편(미정)
- 영상 개입 시점 1~2개
- 선택형 퀴즈 1개
- 퍼즐·그림 활동 중 1개
- 활동 건너뛰기와 영상 재개
- 세션 완료 및 부모 결과 화면

---

## 9. 핵심 검증 지표(KPI)

- 활동 참여율과 건너뛰기율
- 설정 시간 안에 세션을 끝낸 비율
- 종료 시 부모 개입 횟수
- 마무리 활동 완수율
- 부모가 느낀 종료 갈등의 변화
- 유료 콘텐츠 패키지 구매 의향
- 캐릭터 재사용·추가 생성 의향
- 영상 한 편당 분석 비용과 운영자 검수 시간

## 10. 리스크 & 대응

| 리스크 | 대응 |
| --- | --- |
| 영상 권리 문제 | 권리 확보 영상만 사용, 저작권 문제 없음 |
| AI 질문·활동 오류 | 사전 생성·자동 검사·운영자 승인 |
| 활동이 시청을 방해 | 건너뛰기, 개입 간격 조절 |
| 적절한 활동이 없는 영상 | 개입 생략 또는 검수된 범용 활동 제공 |
| 종료 활동이 시간을 늘림 | 30초 이내 제한, 이후 자동 재생 차단 |
| 아동 데이터 문제 | 부모 동의, 최소 수집, 삭제 기능 제공 |
| 인기 콘텐츠 계약 실패 | 무료 콘텐츠로 기술과 수요를 먼저 검증 |
