# 샘플 활동

`tinyping_activities.json` — `oneshot` 파이프라인이 티니핑 6분 영상에서 뽑은 활동 10개다.
파이프라인을 돌리지 않고도 앱까지 붙여볼 수 있게 결과물만 담아 뒀다.

영상 파일은 저작권이 있고 92MB 라 저장소에 없다. `source` 의 경로는 지웠다.

## 쓰는 법

영상과 자막을 구해 등록한 뒤, 이 파일로 활동을 심는다.

```bash
node server/tools/ingest.js <영상.mp4> <자막.srt> \
  --id tinyping-001 --category story --label "이야기" \
  --title "슈팅스타 캐치! 티니핑" --emoji "⭐" --color "#FFD966" --crop-bottom 0.22

node server/tools/from-oneshot.js tinyping-001 samples/tinyping_activities.json
```

`--crop-bottom 0.22` 는 이 영상에 자막이 화면에 구워져 있어서 붙는 값이다.
`frame_sampling.crop_bottom` 에 같은 값이 적혀 있다.

## 이 파일이 어떻게 만들어졌나

`quiz-agents` 스킬로 관찰·지점 선정·출제·검수 네 역할을 나눠 만들고, `oneshot.check` 의
결정론적 가드를 통과한 것이다. `produced_by: "agents"` 가 그 뜻이다.

같은 영상을 다시 돌리면 다른 활동이 나온다. 매번 다른 결과가 나오는 것이 의도다 —
아이가 같은 영상을 다시 봐도 새로운 문제를 만나야 한다.

앱의 따라그리기(`trace`)·퍼즐(`puzzle`)은 여기 없다.

잘라내는 로직이 아직 없어서 검증을 통과한 것이 다 남았다.
